# carecompanion
A companion that helps taking care of the loved one

## Project structure

- `index.html` — Entrypoint (loads CSS, JS, and partials)
- `assets/css/styles.css` — Custom styles
- `assets/js/main.js` — Application logic (SPA rendering, form submit)
- `partials/header.html` and `partials/footer.html` — Reusable fragments

To run locally, open `index.html` in a browser or serve the folder with a simple static server, for example:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
